# GXBRIEL_ZAPRET

Приложение для Windows 10/11 x64: управление zapret2, подбор стратегий обхода DPI, диагностика соединений и проверяемые обновления программы.

## Скачать и запустить

Готовые версии находятся в [разделе выпусков](https://github.com/GxbrieL9/GXBRIEL_ZAPRET/releases/latest). Скачайте `GXBRIEL_ZAPRET-win-x64.zip`, распакуйте в отдельную папку и запустите `GXBRIEL_ZAPRET.exe` от имени администратора. Устанавливать .NET отдельно не требуется.

Выберите стратегию и включите обход. Результат зависит от провайдера и сети; начните с рекомендуемого профиля, а при необходимости запустите диагностику и подбор. Права администратора нужны для сетевого драйвера WinDivert.

## Возможности

- Управление движком zapret2 и стратегиями для Discord, YouTube и других приложений.
- Диагностика сети, проверка соединений и подбор совместимой стратегии.
- Сохранение настроек и восстановление желаемого состояния после перезапуска.
- Патчер распознанных компонентов Antigravity с резервной копией и откатом.
- Проверка выпусков GitHub, проверка подписи и контрольной суммы, обновление основного EXE из интерфейса программы.

Обход DPI не является VPN и не меняет внешний IP-адрес. Патчи Antigravity не гарантируют доступность серверных API по местоположению или доступность конкретной модели.

## Обновление программы

Откройте **Настройки → Движок**, нажмите **Проверить обновления программы**, затем кнопку установки доступной версии. Также уведомление появляется в заголовке программы.

Перед установкой программа проверяет цифровую подпись манифеста, версию, размер и SHA-256 файла. Затем сохраняет предыдущий EXE и перезапускается. Если новая версия не подтверждает запуск, установщик восстанавливает предыдущий EXE. Настройки хранятся отдельно в `%LOCALAPPDATA%\GXBRIEL_ZAPRET`.

Если сервер обновлений недоступен, установленная версия продолжает работать. Обновление движка zapret2 — отдельная операция и использует официальный выпуск его разработчика.

## Сборка из исходного кода

Нужны Windows x64 и .NET SDK 9:

```powershell
dotnet test ui/GxbrielZapret/tests/GxbrielZapret.Tests/GxbrielZapret.Tests.csproj -c Release --filter "FullyQualifiedName~AppUpdateTests|FullyQualifiedName~Antigravity|FullyQualifiedName~UiCrashRegression"
dotnet publish ui/GxbrielZapret/GxbrielZapret.csproj -c Release -r win-x64 --self-contained true -o artifacts/build
```

В репозитории нет локальных журналов, настроек пользователей, закрытых ключей и вложенных Git-подмодулей. Встроенные пакеты среды содержат только распространяемые зависимости. Соответствующие исходники зависимостей находятся в `third-party-sources.zip` рядом с выпусками.

## Проверки и ограничения

Автоматические проверки выполняются на отдельной Windows-машине GitHub Actions и с временными профилями данных. Проверяются подпись, повреждённые загрузки, обновление, откат, сохранность настроек и WPF-интерфейс. Это не заменяет проверку драйвера, антивируса, UAC и реального провайдера на каждом компьютере. Первый публичный выпуск требует такой проверки пользователями; при проблеме приложите версию Windows, версию программы и обезличенное описание ошибки в [обращении](https://github.com/GxbrieL9/GXBRIEL_ZAPRET/issues).
