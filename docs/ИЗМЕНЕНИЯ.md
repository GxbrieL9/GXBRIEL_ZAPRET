# GXBRIEL_ZAPRET 4.0.1

Первый публичный выпуск проекта с обновлением самого приложения через GitHub Releases.

- Добавлены проверка подписи выпуска, проверка SHA-256 и размера EXE.
- Обновление заменяет основной GXBRIEL_ZAPRET.exe и сохраняет предыдущий файл для отката.
- Добавлена проверка запуска новой версии и возврат к предыдущей при неудаче.
- Сохраняются настройки и выбранный каталог пользовательских данных.
- Обновлены распространяемое окружение Cygwin и пакет соответствующих исходников.
- Убраны встроенные утилиты Sysinternals; добавлен захват TCP-соединений через штатный Windows netstat.
- Сохранены исправления патчера CLI Antigravity, включая независимость CLI от выбора настольной установки.

Сборка самостоятельная: устанавливать .NET отдельно не требуется. Для драйвера обхода нужны права администратора. Работа с конкретным провайдером, антивирусом и серверными ограничениями региона зависит от внешних условий; наличие патча не является проверкой ответа модели.

Проверены сценарии файлового обновления и отката, сохранность настроек, подпись и интерфейс. Полный цикл UAC/WinDivert/антивируса/перезагрузки на всех поддерживаемых версиях Windows не проверялся.
