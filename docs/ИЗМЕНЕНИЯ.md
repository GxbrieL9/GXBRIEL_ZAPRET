# GXBRIEL_ZAPRET 4.0.8

- Статус и быстрая проверка сервисов на Главном экране:
  - Добавлен индикатор доступности League of Legends / Riot Games рядом с Discord, YouTube и Telegram.
  - Добавлена кнопка «Проверить» прямо рядом с индикаторами сервисов: параллельный опрос YouTube, Discord и Riot за 2–3 секунды без перехода во вкладку «Диагностика».
- Riot Games / League of Legends:
  - Прямой пропуск доменов `rdevs.com` в движке `winws2` для беспрепятственного скачивания обновлений клиента Riot.
  - Добавлен `clientconfig.rdevs.com` в целевые узлы подбора стратегий для Riot / League of Legends.
- Ускорение тестирования стратегий:
  - Внедрён механизм двухэтапного тестирования кандидатов (Fail-Fast): первичный отсев с параллельным опросом целей по 1 запросу. При сбое любой ключевой цели проверка немедленно прерывается и переходит к следующей стратегии.
  - Время отсева нерабочих пресетов сокращено с ~45 секунд до ~2–3 секунд.

# GXBRIEL_ZAPRET 4.0.7

- Встроенный безопасный маршрут Antigravity (Zero-Config mode):
  - Работает в один клик без стороннего VPN, прокси-клиентов и ручной настройки.
  - Встроенный в приложение петлевой шлюз-relay (AntigravityRelayService) безопасно маршрутизирует запросы к Google AI через проверенные SmartDNS-шлюзы (DNS-AI / MagicDNS).
  - Сквозное TLS-шифрование между Antigravity и Google сохраняется: данные и токены не расшифровываются, сторонние сертификаты не устанавливаются.
  - Системный DNS Windows не изменяется.
  - Кнопка «Следующий маршрут» для быстрого переключения на резервные шлюзы при нагрузке.
  - Поддержка передачи настроек запуска во все переменные (HTTP_PROXY, HTTPS_PROXY, ALL_PROXY, AG_LS_PROXY).

# GXBRIEL_ZAPRET 4.0.1

Первый публичный выпуск проекта с обновлением самого приложения через GitHub Releases.

- Добавлены проверка подписи выпуска, проверка SHA-256 и размера EXE.
- Обновление заменяет основной GXBRIEL_ZAPRET.exe и сохраняет предыдущий файл для отката.
- Добавлена проверка запуска новой версии и возврат к предыдущей при неудаче.
- Сохраняются настройки и выбранный каталог пользовательских данных.
- Обновлены распространяемое окружение Cygwin и пакет соответствующих исходников.
- Убраны встроенные утилиты Sysinternals; добавлен захват TCP-соединений через штатный Windows netstat.
- Сохранены исправления патчера CLI Antigravity, включая независимость CLI от выбора настольной установки.

Сборка самостоятельная: устанавливать .NET отдельно не требуется. Для драйвера обхода нужны права администратора. Работа с конкретным провайдером, антивирусом и серверными ограничениями региона зависит от внешних условий; наличие патча не является проверкой ответа модели.

Проверены сценарии файлового обновления и отката, сохранность настроек, подпись и интерфейс. Полный цикл UAC/WinDivert/антивируса/перезагрузки на всех поддерживаемых версиях Windows не проверялся.
