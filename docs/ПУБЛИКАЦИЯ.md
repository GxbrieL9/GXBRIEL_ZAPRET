# Публикация версии

1. Измените `Version` в `ui/GxbrielZapret/GxbrielZapret.csproj` и подготовьте описание изменений на русском языке.
2. Выполните проверки и отправьте исходники в основную ветку. Обновляйте публичную копию через `tools/export-public-repository.py`, если работаете в исходной локальной структуре с вложенным репозиторием.
3. Создайте тег `vX.Y.Z` с той же версией. Отправка тега запускает Windows-проверки, сборку и автоматическую публикацию выпуска на GitHub Releases.
4. После завершения GitHub Actions выпуск сразу доступен пользователям через встроенный механизм обновления приложения.

Секрет `RELEASE_SIGNING_KEY` настроен в GitHub Actions. Закрытый ключ не хранится в репозитории. Локальная резервная копия ключа находится вне рабочего каталога; её потеря потребует отдельной процедуры смены доверенного ключа. Открытый ключ встроен в приложение.

`tools/new-public-release.ps1` формирует EXE, переносимый ZIP, подписанный `app-update.json`, отделённую подпись `app-update.sig` и `SHA256SUMS.txt`. Исходники сторонних компонентов прикладываются к каждому выпуску. Не редактируйте подписанный манифест после формирования: подпись перестанет проверяться.

Проверка обновления использует официальный API GitHub Releases: https://docs.github.com/en/rest/releases/releases#get-the-latest-release. Прямые ссылки и версия в подписанном манифесте должны соответствовать этому репозиторию. Случайный URL или неподписанный EXE не устанавливается.

## Откат

Установщик сохраняет прежний файл рядом с основным EXE с расширением `.previous-…`. При неподтверждённом запуске новая версия автоматически заменяется проверенной предыдущей. Настройки находятся в отдельном каталоге и не переносятся из архива выпуска.

Для отзыва проблемного выпуска снимите с него статус последнего стабильного выпуска или переведите в предварительные версии. Установленные приложения не понижают версию автоматически. Исправление публикуется с новым, большим номером версии.

## Что пока не подтверждено

Проверки файлового обновления и отката выполняются изолированно, а сборка — на отдельном Windows runner. Полный цикл с UAC, реальным драйвером WinDivert, сторонним антивирусом и перезагрузкой всех поддерживаемых Windows не воспроизведён. Не отмечайте эти сценарии проверенными без соответствующего испытания.
